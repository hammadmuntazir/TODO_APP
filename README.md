# To-Do List App

A small browser-based to-do list practice project built with HTML, CSS, and JavaScript.

## Files

- `index.html` — page structure
- `style.css` — styles
- `script.js` — interactions
- `images/` — UI image assets

## Run

Open `index.html` in a browser. No build step is required for the basic static version.

## Scope

This is a small frontend exercise, not a full-stack task-management service. Review `script.js` to understand how tasks are handled and whether they persist after the page is refreshed.

## Portfolio context

Kept as a small supporting project demonstrating JavaScript fundamentals. For Data Engineering roles, prioritize the Python/SQL pipeline repositories instead.
